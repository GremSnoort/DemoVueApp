# DEMOEXAM HOWTO

## SETUP PROJECT

🍏 **Рабочее окружение на демо-машинах в точности удовлетворяет моему прототипу DemoVueApp**

_(0)_ На демо-машине шаблоны лежат в папке `web`. Эта папка доступна слева в окне Проводника, в закрепах рядом с `Документы`, `Изображения`, etc.

### ❓ **Как создать проект?**

Заходим в папку:
```bash
C:\Users\DEMEXAM\Documents\
```
(или просто в Проводнике тыкаем слева `Документы`)

Создаем в ней папку проекта с указанием личного ФИО, к примеру по шаблону:
```bash
DEMOEXAM_NameSurname
```

_(1)_ Должны получить вот такой путь до папки проекта:
```bash
C:\Users\DEMEXAM\Documents\DEMOEXAM_LuidmilaKrivih
```

Заходим в эту новую, пустую папку проекта и **копируем в нее шаблоны для front & back**:

- копирование шаблона для **front**:
  - из папки шаблонов `web` _(0)_ - копируем папку `frontend` в новосозданную папку своего проекта _(1)_
- копирование шаблона для **back**:
  - из папки шаблонов `web` _(0)_ - копируем папку `pybackend` в новосозданную папку своего проекта _(1)_

### ❓ **Как настроить backend?**

Используем терминал **Git Bash**.

Открыть терминал:
- нажать кнопку `Windows`
- в строке `Поиск` вбить слово `git`
- выбрать иконку с надписью **Git Bash**
- открыть терминал

Должно появиться черное окно с цветным текстом и цветной иконкой на панели снизу.

В черном окне терминала **Git Bash** выполняем (описания действий сопровождаются соответствующими командами):

- заходим в свою папку проекта и далее - в `pybackend`:
```bash
cd Documents
cd DEMOEXAM_<ФИО>
cd pybackend
```
- проверяем, что в строке терминала появился путь до папки `pybackend`
- проверяем содержимое папки с Python virtual env:
```bash
ls -la .venv
```
- в выводе команды должно быть имя `Scripts`
- активируем Python virtual env:
```bash
source .venv/Scripts/activate
```
- в самом начале строки терминала должен появиться префикс `(.venv)`
- создаем файл `requirements.txt` при помощи Проводника в нашей папке `Documents\DEMOEXAM_<ФИО>\pybackend` и копируем в него содержимое соответствующего файла прототипа (одноименного)
- запускаем установку зависимостей (должна отработать прозрачно, так как все уже установлено, но на всякий случай):
```bash
pip install -r requirements.txt
```

Настройка для **backend** завершена, можно приступать к коду.

🔥 **Команда для запуска backend в черном терминале Git Bash:**
```bash
uvicorn app:app --host 127.0.0.1 --port 8080
```

### ❓ **Как настроить frontend?**

Используем терминал **Node command line**.

Открыть терминал:
- нажать кнопку `Windows`
- в строке `Поиск` вбить слово `node`
- выбрать иконку с надписью **Node command line**
- открыть терминал

Должно появиться черное окно с белым текстом и черной иконкой на панели снизу.

В черном окне терминала **Node command line** выполняем (описания действий сопровождаются соответствующими командами):

- заходим в свою папку проекта и далее - в `frontend`:
```bash
cd Documents
cd DEMOEXAM_<ФИО>
cd frontend
```
- проверяем, что в строке терминала появился путь до папки `frontend`

Окружение в шаблонной папке **frontend**, которую мы скопировали к себе из папки шаблонов `web` _(0)_, в точности соответствует запрошенному и удовлетворяет для проекта, можно приступать к коду.

🔥 **Команда для запуска frontend в черном терминале Node command line:**
```bash
npm run dev
```
❗️Данная команда выведет URL голубого цвета (например: `http://localhost:5174/`). Необходимо скопировать этот URL и вставить его в любой браузер, так откроется web-морда сайта.

## ER-diagram

Чтобы получить ER-диаграмму в PostgreSQL, в терминальном окне **Git Bash** зайти в корень своего проекта и выполнить:
```bash
pg_dump -s -U postgres -d postgres > ER.sql
```
Данная команда сложит файл `ER.sql` в корень проекта, рядом с подпапками `frontend` и `pybackend`.
